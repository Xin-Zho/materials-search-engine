## 3. 三个实证缺陷（Round2 教训）

### F1 短语形态失效（最严重）
term_community 的 n-gram 产生 "polymerization composite" 这类**反向词序短语**——
Scopus 精确短语检索几乎无命中（论文实际写作 "composite polymerization"）。
→ 检索语言 ≠ 聚类语言；短语必须用支持论文中实际出现的连续词序，或拆核心词 AND。

### F2 central ≠ expansion 混用
"restorative materials" 是社区**聚类中心词**（识别用），但作为**检索词**无区分度——
dilatometer / laser speckle / linear shrinkage 类目标论文根本不用这套语言。
→ 聚类中心词 ≠ 检索扩展词，必须分离。

### F3 phrase family 冗余
"restorative materials" / "composite restorative materials" / "composite restorative"
是同族变体（token Jaccard 高），生成 4 条冗余 query 全 0 结果。
→ 变体族聚类，每族保留一个代表。

## 4. v2.1.1 机制（QGS-blind）

### 4.1 central_terms ≠ expansion_terms
- **central_terms**：社区聚类核心（top weighted degree）——只用于社区识别与命名，**不直接当 query 词**
- **expansion_terms**：检索扩展词——从支持论文 title+abstract 提取，要求有区分度

### 4.2 Expansion Discriminativeness
```
Disc(t) = log( P(t|C) / P(t|B) )
  P(t|C) = 社区支持论文中含 t 的比例
  P(t|B) = 背景池（全部候选论文/registry 论文）中含 t 的比例
```
- 高 Disc = 社区特有语言（dilatometer / linear shrinkage / laser speckle / ESPI）
- 低 Disc = 泛词（restorative materials / composite / study）→ 排除

### 4.3 短语形态校验
- 候选短语必须**在支持论文原文中按该词序连续出现**（从提取端保证）
- 反向/变体词序（"polymerization composite"）自动拆成核心词 AND 组合或丢弃

### 4.4 phrase family 去冗余
- token Jaccard ≥ 阈值 → 同族，每族保留代表（最长/最短可配）

### 4.5 query 生成（Round3）
```
P 锚 = registry 已验证问题词（"polymerization shrinkage" / "shrinkage stress" 等，
      不从社区硬造——"polymerization composite" 是反面教材）
X 侧 = expansion_terms（Disc 高、形态正确、与 registry 低重叠）
query = TITLE-ABS-KEY("P 锚" AND "expansion")
```

### 7.2 v2.1.4 三级筛选（Evidence→Query Translation 最终形态）

**Level 1 Term Evidence**（词是否有真实独立文献证据）：verbatim + scientific quality gate + df_dedup≥2 + per-community Disc
**Level 2 Query Linguistic Validity**（词能否与已验证 problem anchor 构成真实 Scopus query）：
```
standalone_hits == 0                  → DROP_UNQUERYABLE
standalone_hits > 0, anchored_hits==0 → REAL_PHRASE_BUT_ANCHOR_INCOMPATIBLE
anchored_hits > 0                     → ANCHOR_QUERYABLE
```
**Level 3 Retrieval Utility**（query 真能扩展数据库吗，depth=100 pilot）：
```
R_q(q)                 = anchored query 检索结果（Scopus, depth=100）
R_old                  = 旧 Candidate DB 论文集合（depth run unique DOI，5986 篇）
QueryMCG(q)            = |R_q ∖ R_old|
QueryRetrievalNovelty  = |R_q ∖ R_old| / |R_q|
```
最后才 FREEZE ROUND3 QUERY → 正式 depth=500 → 打开 QGS 算 G2R。

## 8. v2.1.4 冻结规则修订（2026-08-29 凌晨用户定稿）

### 8.1 状态机冻结（timeout ≠ 语义筛除）

```text
STANDALONE_ZERO          standalone_hits==0           （语义筛除）
ANCHOR_INCOMPATIBLE      standalone>0 且 anchored==0  （语义筛除）
ANCHOR_QUERYABLE         anchored>0                   （可通过）
QUERYABILITY_UNKNOWN     执行失败/timeout/导出中断    （非语义判断，--retry 默认 2 次自动重试）
```

只有前两种是真正的语义筛除；UNKNOWN 重试后仍失败保留状态不判死。
（旧命名 DROP_UNQUERYABLE / REAL_PHRASE_BUT_ANCHOR_INCOMPATIBLE / CHECK_FAILED 废弃。）

### 8.2 canonical identity 统一（正式 evaluation 优先 EID）

- 论文 identity：EID（scopus_url `eid=2-s2.0-<digits>` 提取）优先，DOI fallback
- R_old 双键：depth records（eid）∩ scopus_cache（有文本）→ 收集 eid 集合 + doi 集合
- in_old 判定：eid ∈ R_old_eids OR doi ∈ R_old_dois（双键都查，防 eid/doi 口径错位）
- **identity 为空（无 EID 且无 DOI）→ unknown，不计入 MCG**（修 bug：旧版空字符串
  doi 被误算成 new——"133 total new"含无 identity 论文）

### 8.3 selection 规则冻结（QGS-blind，不设复杂 utility 权重）

```text
QueryMCG_pilot >= 2            # pilot 至少证明能独立带来 2 篇新文献
max 3 / source community       # diversity cap（不改 score）
greedy coverage merge          # 每轮选 ConditionalMCG 最大的 query
                               # 停止：best ConditionalMCG < min_mcg
```

- ConditionalMCG(q) = |R_q ∖ (R_old ∪ R_selected)|
- UnionMCG = |∪_{q∈Q} R_q ∖ R_old|
- **hits==depth → pilot_depth_censored=true**（截断观测，MCG 是 top-depth 的 observed，
  不解释为 exhaustive query novelty；不影响 selection）

### 8.7 EVALUATOR_BUG 修复（2026-08-29 上午，冻结前硬闸）

**用户发现**：19 条 condMCG 之和 266 ≠ UnionMCG=86，数学不可能 → 冻结前必须修。

**根因（两层）**：
1. `extract_eid` 只匹配 `eid=2-s2.0-XXX` / `2-s2.0-XXX`，而 Scopus CSV "链接" 列是新版
   `https://www.scopus.com/pages/publications/<pub_id>?origin=resultslist` 格式
   （pub_id = EID 数字部分）→ **EID 提取率 0**，全部走 DOI fallback
2. 无 DOI 论文 identity 变 ""（非 None），`if identity is None` 拦截失败 → 混入
   new_papers（intensity 39 里 30 个是空 identity）→ greedy cond 每轮虚高
   （eid=None,doi=None 永不覆盖），而 union_keys={None} 去重 → **cond 虚高 + union 低估**

**修复**：
- extract_eid 支持 pages/publications/<digits> → 统一 2-s2.0-<digits>（与 depth run 一致）
- IdentityResolver（union-find）：EID↔DOI bridge，canonical key 优先 EID
- 所有集合运算统一 canonical key（in_old / cond / union 同一函数）
- identity 为空（无 EID 无 DOI）→ unknown 不计 MCG
- **硬断言 Σ ConditionalMCG == UnionMCG**（FAIL → 拒绝 freeze，写 audit 报告）

**修复后结果（offline 复用 pilot 缓存重算）**：
- identity audit：raw rows 1237 / unique EID 833 / unique DOI 693 / canonical new 831 /
  both 1048 / eid_only 189（正是旧版 identity="" 的 189 篇）/ doi_only 0 / neither 0 /
  cross-query duplicates 292 / bridged components 693
- **UnionMCG=216（旧 86 严重低估——EID 修复后无 DOI 论文正确判定）**
- greedy 16 条（intensity 39→thermal expansion 36→resin restorations 35→wear
  resistance 22→dilatometer 20→…→arc curing 2），Σ cond == UnionMCG == 216 ✅ PASS
- 重叠率 ~19%（Σobs 268 → union 216），比旧版（133→81）健康得多
- 旧 round3_queries_frozen.json 已标 INVALIDATED_BY_EVALUATOR_BUG（内容保留，
  替代文件 round3_queries_frozen_v215.json，16 条，QGS-BLIND）

**运行模式**：pilot 普通模式默认 skip_cache=False（命中 api_cache 缓存，不烧 API）；
`--offline-cache` 不启动浏览器直接从缓存重算；`--skip-cache` 强制真实检索。

## 17. TermFamily + EvidenceSupport 落地（2026-08-29 14:32，v3.0 Terminology Repair L1）

### 17.1 工具与定义（用户定稿，全部冻结）

**TermFamily 保守归并**（禁语义扩张、禁 Porter stemming，化学词红线：

## 18. Queryability v1（2026-08-29 14:51，用户设计冻结）

### 18.1 两层结构（用户定，不搞加权 score）

- L1 Gate：Q(t) ∈ {DIRECT, ANCHOR, REJECT}（确定性过滤，非连续 score）
  - DIRECT：term 含 {shrinkage, contraction, shrink} 或含 token "photopolymerization"
    （复现用户全部例子：vat/cationic photopolymerization、volume shrinkage、
    shrinkage stress、low shrinkage → DIRECT；stereolithography、methacrylate、
    photocuring → ANCHOR）
  - REJECT reason：FRAGMENT（含 via / 首尾功能词 / 单 token<=3）+ GENERIC
    （泛词黑名单——resin/composite/polymerization/photopolymerization/mechanical
    properties 等 33 词；证据强≠query 好，不因 MissSupport 救泛词）
  - ANCHOR anchor 由 term_type 决定（用户例子映射）：MATERIAL/REACTION/CONTEXT
    → shrinkage AND；METHOD/PROBLEM/UNKNOWN → "polymerization shrinkage" AND
- L2 Conditional Coverage：greedy 每轮 ΔCoverage(t|S)，Cost=1（pilot 后换真实
  query cost / candidate explosion）；tie 取 miss_support 大
- LONG_TAIL_REPAIR：不强行 95/95——无候选 8 篇 + 候选未覆盖 17 篇，支路 =
  citation enrichment / singleton-term rescue
